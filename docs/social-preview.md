# Social Preview Image Spec

## Dimensions

- **Recommended size**: 1280 x 640 px
- **Aspect ratio**: 2:1

## Content & Keywords

Include the following text elements:

- `Cadence` — large, bold, top-center
- `Self-hosted Task Scheduler &amp; Workflow Orchestrator` — subtitle
- `Cron · Workflow · Token Vault` — tagline
- `Cloudflare Workers · Mac · Linux` — deployment badge
- `TypeScript · React · Hono` — tech stack badge

## Color Palette

| Element        | Color                    |
| -------------- | ------------------------ |
| Background     | `#1a1a2e` (dark navy)    |
| Primary text   | `#00d4ff` (cyan)         |
| Secondary text | `#8892b0` (slate)        |
| Accent         | `#64ffda` (teal)         |
| Divider        | `#00d4ff` at 40% opacity |

## Visual Style

- Minimal, dark theme
- Monospace font for code aesthetic
- Subtle horizontal divider between title and tagline
- Optional: small pipeline/node iconography on the right half

## Tools

- Figma / Canva with dark template
- CLI: `magick convert logo.svg -resize 1280x640 social-preview.png`
- Or upload SVG to GitHub directly (GitHub renders SVG in preview cards on supported browsers)
